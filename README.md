攻击者在子域写入一条同名 Cookie 后，会话令牌在下一次请求里被覆盖成攻击者的值，用户被静默切到攻击者账号：契约要求一次响应携带的多条 Set-Cookie 逐条保留，不得合并成一条；属性名大小写不敏感；值允许用双引号包裹，引号内部的分号不参与切分；转义引号按原义还原；同名且同域同路径的重复项按后到覆盖，并保持第一次出现的位置；域名和路径的前导点按同一规则归一，带点与不带点视为同一值；过期时间解析为协调世界时时间戳；非法属性必须出现在解析结果的问题列表中，不得静默丢弃；批量解析时每个响应相互独立。不变量：同一响应重复解析的结果必须相同，属性顺序不得影响解析结果。
